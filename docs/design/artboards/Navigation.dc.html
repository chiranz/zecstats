Rules

The sheet slides over the page — it never pushes content down like today's inline accordion. Groups match the desktop Tools menu one-to-one, so a page lives in exactly one place.

Touch targets are at least 44px tall. The current page is marked with a raised chip, not by renaming a menu trigger.

Donate stays reachable in the sheet and the footer; the "Feeling Generous?" ad strip no longer sits above content.
