A crawler we run dials every address the network gossips about and records whether a Zcash handshake completes. Only nodes that accept inbound connections can ever be counted.

Addresses are masked and each node is placed at city-region level, never finer, so this page cannot be used to target an operator. 9,489 located addresses are not plotted: we have never completed a handshake with them, or not in 90 days.
