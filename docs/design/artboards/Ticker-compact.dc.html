Iteration 3 · event tape wording

Event tape: symbol, value, change

  • Tape: TAG [qualifier] · value · ▲Δ · [age]. No label: the tag is the name.
  • Qualifier only where the tag alone is ambiguous: ATH, 7D, 1D, CLOSE. Price and ZEC/BTC deltas are 24 h.
  • The window (“in 7 days”, “vs previous record”) moves to the hover card’s Change row; the card title keeps the full name.
  • No repeated unit: ZEC/BTC reads 0.01474, ages read 15h / Oct 5.
